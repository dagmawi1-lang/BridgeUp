# 90-second demo script

**0:00–0:12 — The problem**
People want to help, but requests, skills, and opportunities are scattered. BridgeUp puts those connections in one place.

**0:12–0:30 — Support board**
Open the support board, filter by category, and show a request. Explain how a member can offer support without exposing private contact details.

**0:30–0:45 — Ways to help**
Show skill offers and create a sample offer. Explain that contributions can be time, knowledge, or creativity.

**0:45–1:00 — Circles and events**
Join a community circle and an event to demonstrate shared-interest spaces and shared experiences.

**1:00–1:15 — Matching and persistence**
Explain the transparent matching score: shared tags plus a category match. Show the API status indicator and explain that changes can sync to the local API. Matching is deterministic and does not use sensitive personal information.

**1:15–1:30 — Impact and close**
Show the impact summary. Close with the idea that BridgeUp helps people move from wanting to help to finding a concrete way to show up.
