# Roadmap

## Shipped in 7.0
- Accounts with secure password and session handling
- Server-side roles for members, helpers, moderators, and admins
- SQLite database with transactions and constraints
- Live notifications and private conversations over Server-Sent Events
- Blocking, reporting, and a moderation workflow with an audit log
- Rate limits, same-origin (CSRF) checks, validation, and size limits
- Explainable matching on category, skills, urgency, and availability

## Planned
- Email verification, password reset, and optional two-factor sign-in
- Production hosting guide: HTTPS, backups, and monitoring
- Shared pub/sub (for example, Redis) to run more than one server process
- End-to-end encrypted messages
- Screen-reader testing with NVDA and VoiceOver, and browser tests in CI
